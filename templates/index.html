Linear Program

\(\displaystyle\min_{x} \quad c^\top x\)

subject to:

\(A(\delta_i)x+b(\delta_i) \leq 0, \quad i = 1, \ldots, N\)

\(Gx+h \leq 0\)

Quadratic Program

\(\displaystyle\min_{x} \quad c^\top x + \frac{1}{2}x^\top Qx\)

subject to:

\(A(\delta_i)x+b(\delta_i) \leq 0, \quad i = 1, \ldots, N\)

\(Gx+h \leq 0\)

Semidefinite Program (Inequality Form)

\(\displaystyle\min_{x} \quad c^\top x + \frac{1}{2}x^\top Qx\)

subject to

\(F_0 + \displaystyle\sum_{j=1}^{n}F_jx_j \leq 0\)

\(F_0 + \displaystyle\sum_{j=1}^{n}F_j(\delta_i)x_j \leq 0, \quad i = 1, \ldots, N\)

Semidefinite Program (Standard Form)

\(\displaystyle\min_{X} \quad\textbf{tr}(CX)\)

subject to

\(\textbf{tr}(A_jX) + b_j = 0,~j=1,\ldots, \alpha\)

\(\textbf{tr}(A_j(\delta_i)X) + b_j(\delta_i) = 0,~j=1,\ldots, \alpha,~i=1,\ldots,N\)
